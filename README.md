# 🧮 Simple Calculator App

A clean, simple and responsive calculator built using **HTML, Tailwind CSS, and JavaScript**.  
Designed with a smooth UI, hover effects, and mobile-friendly layout.

---

## ✨ Preview

✔ Glass-style UI  
✔ Smooth hover animations  
✔ Fully responsive (mobile + desktop)  
✔ Simple and fast calculator logic  

---

## 🚀 Features

- ➕ Basic arithmetic operations: `+  -  ×  ÷`
- 🧹 **AC button** → clear all input
- ⌫ **X button** → delete last character
- 📱 Fully responsive design (all devices)
- 🎨 Modern UI with Tailwind CSS
- ✨ Smooth hover animation on buttons
- ⚡ Instant calculation using JavaScript

---

## 📁 Project Structure
├── index.html # Main calculator file

---

## 💻 Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (Vanilla)

---

## 🧠 How It Works

- Buttons append values to the display
- `AC` clears everything
- `X` removes last digit
- `=` evaluates expression using JavaScript
- After result, new input resets previous answer
